（開発：ミヤマ工業株式会社 品質管理部）

## ⚡ アプリの特徴

- **1ファイルだけで動きます。** ビルド作業・インストール不要。`outline.html` を直せばそれがそのままアプリです。
- 画面はすべて **React**（CDNから読み込み）で書かれています。
- データは **Firebase（Firestore / Storage）** に保存されます。
- **日本語とインドネシア語**を切り替えられます。
