## ⚠️ 重要：引き継ぎ後も **ミヤマ工業側に残る** もの

コードは長坂コーテングで自由に編集・公開できますが、
**次の3つは現時点でミヤマ工業（杉本）の環境に残ります。**
将来的に完全独立したい場合は、別途移行作業が必要です。

### ① データベース（Firebase）

- プロジェクトID： **`personal-60023`**
- 管理者：ミヤマ工業 杉本
- **長坂コーテングは Firebase の管理画面（コンソール）にはアクセスできません。**

**できること／できないこと**

| 操作 | 可否 |
|---|---|
| アプリからのデータ読み書き（マスター登録・計画作成・実績記録） | ⭕ できます |
| 画面やロジックの修正・公開 | ⭕ できます |
| データベースの**アクセス権限ルール**の変更 | ❌ 杉本に依頼 |
| 新しいデータの種類（コレクション）の追加 | ⚠️ 権限ルールの変更が必要な場合は杉本に依頼 |
| データの一括バックアップ・エクスポート | ❌ 杉本に依頼 |

> **なぜ分離されていないのか**
> `personal-60023` は長坂コーテング専用ではなく、他にも多数のアプリが相乗りしています。
> そのため権限をお渡しすると、**無関係なアプリのデータまで閲覧・削除できてしまう**ため、
> 今回は権限はお渡ししない形としています。

**完全独立したくなったら** → 長坂コーテング名義で Firebase プロジェクトを新規作成し、
データを移行します。`docs/03_データ構造.md` に移行対象の一覧があります。杉本にご相談ください。

### ② 翻訳機能（インドネシア語への自動翻訳）

- 呼び出し先： `https://dawn-wave-20e6.motsu922.workers.dev`
- 管理者：ミヤマ工業 杉本（Cloudflare Workers）

マスター保存時の自動翻訳はここを経由します。
**停止すると翻訳だけが動かなくなります**（アプリ本体や既に翻訳済みのデータは影響なし。日本語表示のまま使えます）。

変更する場合は `outline.html` 内のこの行を書き換えてください。

```js
const TRANSLATE_URL='https://dawn-wave-20e6.motsu922.workers.dev';
```

## 🔐 セキュリティ上の注意

### やってはいけないこと

- **GitHub のパスワードやトークンをコードに書かないでください。**
  （このリポジトリのファイルは誰でも見られる可能性があります）
- `firebase/firestore.rules` は「ログインした人は全データ読み書き可」という設定です。
  **アプリを社外に公開しないでください。** URLを知っていてもログインできなければ中は見えませんが、
  アカウント管理は厳重にお願いします。

### Firebase の設定値について

`outline.html` の先頭にある `apiKey` などは、**公開されても問題ない値**です
（Webアプリ用の識別子であり、パスワードではありません）。
実際のアクセス制御は「ログイン（メール＋パスワード）」と「権限ルール」で行っています。
