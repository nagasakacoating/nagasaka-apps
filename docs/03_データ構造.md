## アウトライン工程アプリ（outline.html）

### `outlineMaster` — 製品マスター

ドキュメントID = **呼称**（例：`A-123`、旧「背番号」）

| フィールド | 型 | 内容 |
|---|---|---|
| `partNo` | 文字列 | 品番（例：1234-56789） |
| `name` / `name_id` | 文字列 | 品名（日本語／インドネシア語） |
| `procIds` | 配列 | この製品が通る工程のID（例：`['p1','p9']`） |
| `updatedAt` | 文字列 | 最終更新日 |
| `productImg` | URL | 製品写真 |
| `qrText` / `kanbanQr` | 文字列 | QR照合用の文字列 |
| `locNo` | 文字列 | 端数品置き場所（ロケ番号） |
| `videoUrl` | URL | 作業動画 |
| `shape` | オブジェクト | 形状確認ポイント（写真3枚 `img`/`img2`/`img3`、特徴 `points[]`、類似品 `similars[]`、注意 `notes[]`） |
| `teekin` | オブジェクト | テーキン（`img` / `note`） |
| `hanger` | オブジェクト | ハンガー（全体写真 `img`、特徴4 `features[]`、仕様 `spec[]`、注意 `cautions[]`） |
| `steps` | 配列 | 作業の流れ |
| `cautions` | 配列 | 注意ポイント |
| `tools` | 配列 | 必要道具類 |
| `packing` | オブジェクト | 収容数・梱包荷姿（`capacity`、荷姿 `patterns[]` 最大4） |
| `boxes` | 配列 | 納入箱（最大4） |
| `idMark` | オブジェクト | 識別マーク（全体写真・拡大写真） |
| `kanbans` | 配列 | かんばん情報（最大4） |
| **`sheets`** | オブジェクト | **工程ごとの要領書**（後述） |

#### `sheets` — 工程ごとの要領書・工数

工程IDをキーにしたオブジェクトです。

```
sheets: {
  p1: {                        ← 工程ID（製品揃え）
    kosu: "0.2",               ← 1箱あたりの工数（分）★計画表の計算に使用
    steps: [ {img, text, text_id} ],   ← 作業手順（写真＋コメント）
    notes: [ "注意事項" ]
  },
  p9: { ... }                  ← 別の工程の要領書
}
```

> **`kosu`（1箱工数）が未登録だと、計画表の予定時間・先行遅れが計算されません。**

#### 翻訳フィールドの仕組み

インドネシア語は `_id` を付けたフィールドに保存されます。
`_src` は「翻訳したときの日本語」で、日本語が変わった項目だけ再翻訳するために使います。

```
name:     "ブラケット ASSY"      ← 日本語
name_id:  "Bracket ASSY"        ← 自動翻訳されたインドネシア語
name_src: "ブラケット ASSY"      ← 翻訳元（これと name が違えば再翻訳）
```

### `workOrders` — 作業指示（計画＋実績）

計画の1行と、その実績が**1つのドキュメント**になっています。

| フィールド | 内容 |
|---|---|
| `date` | 日付（`2026-10-08`） |
| `procId` / `procName` | 工程 |
| `order` | 並び順（10刻み。↑↓で入れ替え） |
| `kind` | `item`＝製品の行 / `task`＝作業の行（ハンガーマン等） |
| `hinban` / `partNo` / `hinbanName` | 呼称・品番・品名 |
| `targetBoxes` | 目標箱数 |
| `taskName` / `durMin` | 作業名・所要時間（作業の行のみ） |
| `kosu` / `capacity` | 1箱工数・収容数（**計画作成時点の値を固定保存**） |
| `assignedWorkerId/Name` | 管理者が割り当てた担当者 |
| `workerId/Name` | 実際に作業した担当者 |
| `status` | `pending`（未着手）/ `running`（作業中）/ `paused`（一時停止）/ `done`（完了） |
| `startAt` / `endAt` | 実際の開始・終了時刻 |
| `doneBoxes` / `fraction` | 完了箱数・端数（個） |
| `pauses` | 休憩・ライン応援の記録 `[{type, from, to}]` |
| `anomalies` | 異常の記録 `[{at, comment}]` |
| `stdMin` / `actMin` / `diffMin` / `pausedMin` | 完了時に確定する 標準・実働・先行遅れ・停止時間（分） |
| `adjustMin` / `adjustNote` | 管理者による評価の調整 |

#### 先行・遅れの計算式

```
標準時間  = 1箱工数 × (完了箱数 + 端数 ÷ 収容数)
実働時間  = (終了 − 開始) − 休憩・一時停止
先行遅れ  = 標準時間 − 実働時間        ＋なら先行、−なら遅れ
評価      = 先行遅れ + 管理者の調整値
```

### `procSettings` — 工程ごとの始業・休憩設定

ドキュメントID = 工程ID（`p1` など）

| フィールド | 内容 |
|---|---|
| `startTime` | 始業時刻（`08:10`） |
| `breaks` | 休憩 `[{label:'昼休憩', from:'12:00', to:'12:45'}]` |

計画表の「開始予定・終了予定」は、この設定をもとに
**休憩をまたぐ分を自動で後ろ倒し**して計算しています。

## 画像の保存先（Firebase Storage）

```
outline-images/{呼称}/{項目名}
  例： outline-images/A-123/productImg
       outline-images/A-123/shape/img2
       outline-images/A-123/sheet/p1/0     ← 工程p1 の手順1枚目
```

> 呼称を変更しても、保存済み画像のフォルダ名は旧呼称のままですが、
> 画像のURLはデータに保存されているため**表示には影響しません**。
