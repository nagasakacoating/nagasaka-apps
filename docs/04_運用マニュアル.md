# 04. 運用マニュアル（アウトライン工程アプリ）

現場での使い方です。**管理者編**と**作業者編**に分かれています。

---

# 【管理者編】

## 準備①　始業時刻と休憩を設定する（工程ごとに1回だけ）

1. 工程を選ぶ
2. 画面下の **「📅 スケジュール編集」**
3. **「⏰ 始業・休憩設定」**
4. 始業時刻と、休憩1・昼休憩・休憩2 の時間帯を入力 → 保存

> 初期値は 始業8:10 ／ 10:00-10:20 ／ 12:00-12:45 ／ 15:00-15:20 です。
> ここを設定すると、計画表の「開始予定・終了予定」が自動で計算されます。

## 準備②　製品マスターを登録する

1. 画面下の **「⚙ マスター」**
2. 上の欄に **呼称**（例：`A-123`）を入れて「追加」
3. 追加された製品をタップして登録

### 「基本情報」タブ（最初に必ず）

| 項目 | 説明 |
|---|---|
| 品番 | 実際の品番（例：1234-56789） |
| 品名 | 日本語。インドネシア語は保存時に自動翻訳されます |
| **工程名** | **この製品が通る工程をすべて選択（複数可）** |

> ⚠️ **工程名を選ばないと、その工程の画面にこの製品が出てきません。**
> マスター一覧で「⚠ 工程名未登録」と赤く出ている製品は要対応です。

### 「要領書・工数」タブ（作業指示を使うなら必須）

1. 上のボタンで**工程を選ぶ**
2. **1箱あたり工数（分）** を入力 ← これが予定時間の基準になります
3. **手順**を「＋手順を追加」で登録（写真＋コメント）
4. 注意事項を入力 → **保存する**

> 工程ごとに別々の要領書を登録できます。
> 工数が未登録だと、計画表に「未登録」と赤く出て、予定時間・先行遅れが計算されません。

### その他のタブ

製品写真・形状確認ポイント（写真3枚＋類似品との違い）・テーキン・ハンガー・
作業の流れ・注意ポイント・必要道具・収容数と荷姿・納入箱・識別マーク・かんばん情報
を登録できます。作業者は「製品検索」からいつでも見られます。

> **「保存する」を押すと、日本語が自動でインドネシア語に翻訳されます。**
> 項目が多いと初回は数十秒かかります。2回目以降は変更した項目だけなので速くなります。

## 準備③　担当者を登録する

マスター管理 → **「👤 担当者管理」** → 氏名を入れて追加

---

## 毎日の作業：スケジュールを組む

1. 工程を選ぶ → **「📅 スケジュール編集」**
2. 日付を選ぶ
3. **「製品の行」** を選び、呼称・数量（箱）・担当者（任意）を入れて **「＋行を追加」**
4. 製品以外の作業（ハンガーマン・清掃など）は **「作業の行」** に切り替えて、作業名と所要時間を入力
5. **↑↓** で順番を入れ替え、**×** で削除

> **「⧉ 前日から複製」** で前日の計画をまるごとコピーできます。毎日ゼロから組む必要はありません。

画面上部に **予定時間の合計** と **終業見込み** が出ます。
休憩時間は自動で考慮され、休憩をまたぐ作業は後ろ倒しで計算されます。

---

## 実績を確認する

### 履歴（画面下「📋 履歴」）

直近7日の完了分を一覧表示。日付・担当者・呼称・開始終了・完了箱数・実働・先行遅れ・異常が見られます。

### 評価の調整（異常で遅れたとき）

1. 履歴で該当の行の **「⚖ 調整」**
2. 異常コメントを確認しながら **調整時間（分）** と **理由** を入力
   - 遅れを取り消すなら **プラス**（例：設備故障で15分止まった → `+15`）
3. 保存

→ 調整した分は、計画表・履歴・評価グラフ**すべての集計に反映**されます。

### 評価グラフ（画面下「📊 評価」）

- **日／月／年** を切り替えて推移を確認
- 先行・遅れの棒グラフ（上向き緑＝先行、下向き赤＝遅れ）
- 完了箱数の推移
- **担当者別・製品別**の集計
- 「全工程」ボタンで工程をまたいだ集計も可能

# 【作業者編】

## 1. ログインして工程を選ぶ

メールアドレスとパスワードでログイン → 自分の工程を選ぶ → **計画表**が開きます。

## 2. 担当者を選ぶ

画面上部の **「今の担当者」** から自分の名前をタップ。
（決まっていない場合は「⏭ スキップ」でも作業できます）

## 3. 計画表を上から順に進める

青枠の **「▶ 次の作業」** が今やるべき作業です。
**「作業開始」**をタップしてください。

計画表では各行について次が分かります。

| 列 | 内容 |
|---|---|
| 予定時間 | この製品にかかる基準時間 |
| 予定 | 開始予定 → 終了予定の時刻 |
| 実績 | 実際の開始 → 終了 |
| 進捗 | 何箱終わったか |
| 差 | 予定より早い（＋）か遅い（−）か |

## 4. 要領書を確認する

作業開始を押すと **作業手順** が出ます。
内容を確認したら **「確認しました」にチェック** → **「▶ 作業開始」**

> チェックを入れないと開始できません。必ず手順を読んでから作業してください。

## 5. 作業中の画面

| ボタン | 使うとき |
|---|---|
| **📦 1箱完了** | 1箱終わるたびに押す |
| ↩ 1つ戻す | 押し間違えたとき |
| ☕ 休憩 | 休憩に入るとき（時間が止まります） |
| 🤝 ライン応援 | 応援に行くとき（時間が止まります） |
| ▶ 再開 | 休憩・応援から戻ったとき |
| ⚠ 異常 | トラブルがあったとき（内容を記録） |
| ■ OUT 作業終了 | その製品が終わったとき |

画面右上には **現在時刻・終了予定・経過/実働**、
中央に **進捗** と **先行・遅れ（±分）** がリアルタイムで出ます。

> 休憩・応援中は時間がカウントされないので、評価に影響しません。
> 終了予定時刻は自動で後ろにずれます。

## 6. 作業を終える

1. **「■ OUT 作業終了」**
2. 最後の箱が満数でなければ **端数（個）** を入力
3. **「完了」**

### 結果が表示されます

```
        ✅ 作業完了
           予定より
          3 分
      ▲ 早く終わりました

   完了箱数   48 / 48 箱
   予定時間   10.0 分
   実働        7.0 分
   開始 → 終了  08:10 → 08:17

   今日の累計（3件）      +12 分
```

**予定より早かったか遅かったか**が一目で分かります。
下に**今日の累計**も出るので、その日のトータルも確認できます。

**「次の作業へ ▶」** を押すと計画表に戻り、次の行が繰り上がります。

## 7. 製品の情報を見たいとき

画面下の **「🔍 製品検索」** から、呼称・品番・品名のどれでも検索できます。

製品を選ぶと13項目の情報が見られます。

製品写真／形状確認ポイント／テーキン／ハンガー写真／作業の流れ／注意ポイント／
必要道具類／収容数・梱包荷姿／納入箱／識別マーク／かんばん情報／端数品置き場所／QR照合

写真はタップで拡大できます。

## 8. インドネシア語に切り替える

画面右上の **「ID」** をタップ。
画面の表示だけでなく、**登録された要領書や注意事項もインドネシア語**で表示されます。
日本語に戻すときは **「JP」** です。

---

## 作業を中断したとき

タブレットを閉じたり、間違って戻ってしまっても大丈夫です。
計画表の上に **「⏱ 進行中の作業」** として残っているので、
**「作業に戻る」** で続きから再開できます。
