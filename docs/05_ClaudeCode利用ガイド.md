# 05. Claude Code でコードを修正する手順

**Claude Code** は、AIに日本語で指示するとコードを直してくれるツールです。
プログラミングの知識がなくても「ここの文字を大きくして」と頼むだけで修正できます。

> 📌 このリポジトリには `CLAUDE.md` という説明書が入っています。
> Claude Code は起動時にこれを自動で読み、**このアプリの構造を理解した状態**で作業を始めます。

---

## A. 準備（最初に1回だけ）

### 必要なもの

| 必要なもの | 説明 |
|---|---|
| Claude の有料プラン | Claude Pro / Max など。Claude Code の利用に必要です |
| パソコン | Windows / Mac どちらでも可 |
| インターネット接続 | 必須 |

### ステップ1：Git をインストール

GitHubからコードを取ってくるために必要です。

1. https://git-scm.com/downloads を開く
2. お使いのOSを選んでダウンロード → インストール（設定はすべて初期値でOK）

### ステップ2：Claude Code をインストール

**公式の手順はこちら：** https://docs.claude.com/ja/docs/claude-code/overview

デスクトップアプリ版・ターミナル版がありますが、**デスクトップアプリ版が簡単**です。
（画面上でファイルやブラウザを見ながら作業できます）

ターミナル版を使う場合は、Node.js を入れてから次のコマンドを実行します。

```bash
npm install -g @anthropic-ai/claude-code
```

### ステップ3：ログイン

インストール後、初回起動時に Claude のアカウントでログインします。

### ステップ4：コードを自分のパソコンに取ってくる

パソコンの好きな場所（例：デスクトップ）にコードのコピーを作ります。
ターミナル（Windowsなら「Git Bash」）を開いて、次を実行します。

```bash
cd ~/Desktop
git clone https://github.com/nagasakacoating/nagasaka-apps.git
cd nagasaka-apps
```

これで `nagasaka-apps` というフォルダができます。

## B. 修正の流れ（毎回これを繰り返します）

### ① 最新の状態にする（作業前に必ず）

他の人が直しているかもしれないので、まず最新を取り込みます。

```bash
cd ~/Desktop/nagasaka-apps
git pull
```

### ② Claude Code を起動する

```bash
claude
```

デスクトップアプリ版の場合は、アプリを開いて `nagasaka-apps` フォルダを選びます。

### ③ 日本語で指示する

そのまま日本語で頼んでください。**ファイル名や行番号を知らなくても大丈夫です。**

```
outline.html の注意ポイントの文字をもう少し大きくして
```

Claude が該当箇所を探して修正し、「ここをこう直しました」と報告します。

### ④ 確認する

**変更がどうなったか必ず確認してください。**

```
変更した画面をブラウザで見せて
```

と頼むと、Claude がブラウザで開いて見せてくれます（デスクトップアプリ版）。

### ⑤ GitHubに反映して公開する

```
この変更をGitHubに反映して
```

と頼むか、自分で次を実行します。

```bash
git add -A
git commit -m "注意ポイントの文字を大きくした"
git push
```

**2〜3分で自動的にWebサイトに反映されます。**

### ⑥ 公開されたか確認

- GitHubの **Actions** タブで緑のチェック ✅ を確認
- https://nagasakacoating.github.io/nagasaka-apps/outline.html を開いて確認

## C. 指示の出し方のコツ

### 良い指示の例

| 目的 | 指示の例 |
|---|---|
| 文字を変える | `計画表の「作業開始」ボタンを「スタート」に変えて` |
| 見た目を変える | `注意ポイントの背景をもっと目立つ赤系にして` |
| 工程を増やす | `工程に「11. 梱包検査」を追加して。IDはp11で` |
| 項目を増やす | `マスターの基本情報タブに「得意先名」の入力欄を追加して` |
| 不具合を直す | `スマホで見ると計画表の右側が切れる。直して` |
| 調べてもらう | `先行・遅れはどこで計算してる？` |

### コツ

- **「どの画面の」「何を」「どうしたいか」** を書くと正確に伝わります
  - ❌ `文字を大きくして`
  - ⭕ `要領書画面の手順の文字を大きくして`
- **分からないことは質問してOK** です。`このアプリのデータはどこに保存されてる？` など
- **一度に1つずつ**頼むほうが確実です

### 困ったときの指示

```
さっきの変更を取り消して
```
```
画面が真っ白になった。直して
```

## D. 守っていただきたいこと

### ⚠️ 本番アプリに注意

**`nagasaka.html`（生産計画）は現場が本番で使用中です。**

- 現場が使っている時間帯に変更しない（昼休み・終業後に）
- 変更したら必ず実機で動作確認する

まずは **`outline.html`（テスト中）で練習**してから本番に触ってください。

### ⚠️ 内容を確認してから公開する

Claude Code は優秀ですが、**間違えることもあります。**

- 「こう直しました」の説明を読む
- 画面を見て確認する
- おかしければ `取り消して` と伝える

**確認せずに `git push` しないでください。**

### ⚠️ やってはいけないこと

| 禁止 | 理由 |
|---|---|
| パスワードやトークンをコードに書く | リポジトリは公開されています |
| `PROCESSES` の `id`（p1〜p10）を変える | 登録済みのマスター・計画データとの紐付けが切れます |
| Firebase の設定（firebaseConfig）を変える | データベースに繋がらなくなります |

これらは `CLAUDE.md` にも書いてあるので、Claude Code も止めてくれるはずですが、念のため覚えておいてください。

## E. 元に戻したいとき

### 方法1：Claude Code に頼む

```
さっきの変更を取り消して、GitHubにも反映して
```

### 方法2：GitHubのサイトで戻す

1. リポジトリの **Commits**（履歴）を開く
2. 戻したい変更をクリック
3. 右上の **…** → **Revert** → **Commit changes**
4. 2〜3分で元に戻ります

### 方法3：コマンドで戻す

```bash
git log --oneline -5     # 履歴を見る（例：89fcdce 注意ポイントの文字を大きくした）
git revert 89fcdce       # その変更を取り消す
git push                 # 公開
```

## G. よくある質問

**Q. 間違えて変なコードにしてしまった。元に戻せる？**
A. 戻せます。上の「E. 元に戻したいとき」をご覧ください。GitHubに履歴が全部残っています。

**Q. 自分のパソコンで変更しても、他の人には見えない？**
A. `git push` するまでは自分のパソコンの中だけです。push すると公開されます。

**Q. ローカルで動かすとデータは？**
A. **本番と同じデータベースに繋がります。** 試しに登録したデータも本番に残るので注意してください。

**Q. Claude Code の料金は？**
A. Claude の有料プランに含まれます。詳しくは https://claude.com/pricing

**Q. どうしても分からない**
A. ミヤマ工業 品質管理部 杉本 までご連絡ください。
